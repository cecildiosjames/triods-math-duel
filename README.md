# Triods Math Duel

Two-player maths quiz for classes 1 to 12 by **Triods Tuition**.

- **Same phone:** put the phone flat between two players and race face to face.
- **Online with a friend:** each player uses their own phone. One creates a room and shares the 5-digit code (or a link), the other joins. Needs internet on both phones.
- **Duel mode:** same question for both players, first correct tap wins the point.
- **Marathon mode:** both race the clock on their own questions; most correct answers wins.
- 30 concepts, four hardness levels, four answer options on every question.
- Installable: Android (Chrome: Install app), iPhone (Safari: Share, Add to Home Screen). Same-phone play works offline.

Plain HTML/JS, no build step. Online play uses PeerJS (peer-to-peer, loaded only when needed).
