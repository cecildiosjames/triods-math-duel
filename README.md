# Triods Math Duel

Two-player, face-to-face maths quiz for classes 1 to 12 by **Triods Tuition**.
Put the phone flat between two players. Pick the class, hardness, time and topics, then race to answer.

- **Duel mode:** same question for both players, first correct tap wins the point.
- **Marathon mode:** both race the clock on their own questions; most correct answers wins.
- 30 concepts, four hardness levels, four answer options on every question.
- Works offline once opened. Installable on Android (Chrome: Install app) and iPhone (Safari: Share, Add to Home Screen).

Plain HTML/JS, no build step. Open `index.html` through a web server (for example GitHub Pages).
